# 커리어 내비 (Career Navi)

> **당신의 다음 커리어를, 데이터로 안내합니다.**

이력서를 넣으면 가진 역량을 분석해 **갈 수 있는 커리어 경로 3개**를 제시합니다.
그중 하나는 스스로는 떠올리기 어려운 **"이 길도 있어요"** 경로입니다.

## 무엇을 만드는가

```
① 이력서 붙여넣기 (또는 샘플 프로필 원클릭)
        ↓  LLM — "무엇을 했는가" 추출
② 스킬 추출  — 직무명이 아니라 행위 단위로 원자화
        ↓  코드 — "얼마나 통하는가" 계산
③ 스킬 지도  — 전이성 2×2 (레버리지 / 락인 / 커먼 / 노이즈)
        ↓
④ 경로 3선   — 적합도 · 예상 소요 · 부족 역량 · 첫 단계
        ↓
⑤ 공유 카드  — 이미지 1장
```

**설계 원칙 한 줄**
> 추출·해석은 LLM, 점수 계산은 코드. 점수를 LLM에 맡기면 매번 값이 달라져 설명할 수 없다.

## 역할 분담 (파일 소유권)

같은 파일을 두 명이 동시에 수정하지 않습니다. AI 에이전트는 파일을 통째로 재작성하는 일이 잦아 머지 충돌 비용이 큽니다.

| | **A** — 파이프라인 축 | **B** — 표현 축 |
|---|---|---|
| 책임 | 입력 → LLM 추출 → 스코어링 → `AnalysisResult` | `AnalysisResult` → 화면 |
| 소유 | `app/api/**` · `lib/**` · `data/**` | `app/page.tsx` · `components/**` · 스타일 |
| 산출 | JSON을 뱉는 API | 랜딩 · 스킬 지도 · 경로 카드 · 공유 이미지 · 모바일 |

**공동 소유 (합의 후 수정)** — `types.ts`

---

## ⚠️ 계약 규칙

[`types.ts`](./types.ts) 가 두 사람 사이의 **유일한 인터페이스**입니다.

- A는 이 타입을 **뱉는** 책임, B는 이 타입을 **그리는** 책임만 집니다.
- **이 파일은 반드시 합의 후 수정합니다.** 여기가 흔들리면 통합에서 프로젝트가 터집니다.
- B는 [`data/mock-result.json`](./data/mock-result.json) 으로 A를 기다리지 않고 화면을 완성합니다.
  마지막에 실제 API로 스위치만 합니다.
- AI에게 코드를 시킬 때는 **`types.ts`를 컨텍스트로 함께 넣으세요.** 안 그러면 둘의 결과물이 어긋납니다.

## 시작하기

```bash
git clone https://github.com/alsgur3667/wanted.git
cd wanted
npm install
cp .env.example .env.local   # 키 입력 후
npm run dev
```

### 환경 변수

| 키 | 용도 |
|---|---|
| `ANTHROPIC_API_KEY` | 이력서 추출 · 경로 설명 생성 |
| `DAILY_CALL_LIMIT` | 일일 LLM 호출 상한 (비용 방어) |

> `.env.local` 은 **절대 커밋하지 않습니다.** 유료 API 자부담이라 키 유출 = 요금 폭탄입니다.

## 폴더 구조

```
app/
  api/analyze/route.ts    # A · 분석 엔드포인트
  page.tsx                # B · 랜딩 + 결과
components/               # B · UI
lib/
  prompts/                # A · LLM 프롬프트
  scoring.ts              # A · 전이성 · 적합도 계산
data/
  mock-result.json        # 공용 · B의 개발 기준
  ontology.json           # A · 스킬 온톨로지
  jd-snapshot.json        # A · 채용공고 스냅샷
types.ts                  # 공동 · 계약
docs/                     # 계획 · 스키마
```
