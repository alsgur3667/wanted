데이터 점검판

직무마다 어떤 역량을 왜 요구하는지 근거를 그대로 폅니다. 화면에서 고친 것은 보정 내려받기로 data/overrides.json 을 만들어 저장소에 두면 다음 산출부터 적용됩니다. 원본 수치는 덮어쓰지 않습니다.

줄의 기반 수치 고치기

공고 자격요건/우대 건수와 해설 글의 필수/우대 판정을 직접 넣습니다. 비워 두면 원본 값을 그대로 씁니다. 이 값들은 필수/우대 판정과 강도를 다시 계산하는 데 쓰입니다. 줄이 많아 위 칸에서 직무나 역량으로 좁힌 뒤 고치세요.

줄 추가

공고에도 해설에도 안 나왔지만 그 직무에 필요한 것을 손으로 넣습니다. 역량 칸에 사전에 없는 이름을 적으면 새 역량으로 만듭니다.
