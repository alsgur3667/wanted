## 1. 서비스 개요

| 항목 | 정의 |
|---|---|
| 서비스명 | **커리어 내비 · Career Navi** |
| 서비스 범주 | 역량 기반 커리어 탐색·채용 지원 서비스 |
| 핵심 태그라인 | **직무명이 아니라 역량으로** |
| 한 문장 설명 | 개인의 보유 역량과 기업의 요구 역량을 같은 언어로 연결해, 직무명 때문에 놓치던 커리어 경로와 후보를 근거와 함께 보여준다. |
| 개인에게 주는 결과 | 갈 수 있는 커리어 경로 3개, 보유·부족 역량, 첫 학습 단계 |
| 기업에게 주는 결과 | 역량 기준 지원자·추천 인재, 일치·부족 역량과 판단 근거 |
| 현재 제품 단계 | 실제 데이터 구조와 추천 로직을 가상 회사·공고·후보에 연결한 기능 목업 |

커리어 내비는 사용자의 미래를 대신 결정하는 서비스가 아니다. 지금까지 해온 일에서 확인되는 역량을 바탕으로 **가능한 방향과 그 근거를 보여주는 안내자**다.

## 2. 문제 정의

### 2.1 공통 문제

채용 시장에서는 사람과 기회를 주로 직무명으로 분류한다. 하지만 회사마다 같은 일을 다른 직함으로 부르기도 하고, 서로 다른 직무에서도 같은 역량을 사용한다.

그 결과 두 사용자가 서로를 놓친다.

| 개인 | 기업 |
|---|---|
| 지금까지 해온 일이 다른 직무에서도 쓰일 수 있는지 알기 어렵다. | 채용 직무명과 이전 직무명이 다른 후보를 검색 단계에서 놓친다. |
| 직무 전환을 생각해도 무엇을 이미 갖췄고 무엇이 부족한지 알기 어렵다. | 지원자의 경험이 공고의 어떤 요구 역량과 연결되는지 빠르게 비교하기 어렵다. |
| 일반적인 직업 추천은 결과가 나온 이유를 확인하기 어렵다. | 단일 적합도 숫자만으로는 검토·면접에서 무엇을 확인해야 하는지 알기 어렵다. |

프로젝트 내부 KLIPS 분석에서는 연속 차수 관측 89,337건 중 연간 직종 전환 비율이 5.9%였다. 이 수치는 전환의 원인을 증명하지는 않지만, 직무 이동이 흔하지 않다는 문제 배경으로 사용한다.

### 2.2 기존 방식의 한계

| 기존 방식 | 유용한 점 | 남는 문제 |
|---|---|---|
| 직무명·경력 연차 검색 | 빠르고 이해하기 쉽다. | 직함이 다른 전환 후보를 놓친다. |
| 적성·성향 검사 | 자기 이해의 출발점이 된다. | 실제 업무 경험과 채용 요구 역량의 연결이 약하다. |
| 키워드·유사도 점수 | 많은 문서를 빠르게 정렬한다. | 어떤 역량이 왜 맞는지 설명하기 어렵다. |
| 생성형 AI의 자유 추천 | 다양한 아이디어를 제시한다. | 같은 입력에도 결과가 달라질 수 있고 점수 근거가 불명확하다. |

커리어 내비의 기획 초점은 기존 방식을 모두 대체하는 것이 아니라, 그 사이에 빠져 있던 **설명 가능한 역량 연결**을 제공하는 데 있다.

## 3. 타깃 정의

### 3.1 타깃 선정 기준

핵심 타깃은 나이·연차보다 다음 조건으로 정의한다.

- 자신의 실제 업무 경험을 문장으로 설명할 수 있다.
- 현재 직무명만으로 다음 선택지를 찾는 데 한계를 느낀다.
- 추천 결과뿐 아니라 왜 가능한지 확인하려 한다.
- 개인 또는 후보자의 부족한 점만이 아니라 이미 가진 역량을 활용하려 한다.

### 3.2 1차 타깃 — 다음 이동을 고민하는 경력자

**정의**

한 번 이상의 업무 경험이 있고, 이직·직무 전환·역할 확장을 검토하지만 현재 직함 밖의 선택지를 찾기 어려운 사람.

**상황**

- 같은 직군 안에서 더 적합한 세부 직무를 찾고 있다.
- 인접 직무로 옮기고 싶지만 현재 경험이 얼마나 인정될지 모른다.
- 완전히 다른 직군도 궁금하지만 막연한 추천은 신뢰하지 않는다.
- 채용공고를 보며 무엇부터 보완해야 하는지 판단하기 어렵다.

**핵심 요구**

1. 내가 갈 수 있는 구체적인 직무를 알고 싶다.
2. 이미 가진 역량이 새 직무에서 어떻게 쓰이는지 알고 싶다.
3. 부족한 역량과 첫 준비 단계를 알고 싶다.
4. 추천 결과의 근거를 직접 확인하고 싶다.

**브랜드 메시지**

`해온 일 안에서, 다음 길의 근거를 찾습니다.`

### 3.3 2차 타깃 — 전환 가능성을 함께 보는 채용 담당자

**정의**

채용공고의 요구 역량을 기준으로 지원자 또는 인재풀을 검토하며, 동일 직무 경력자만으로 후보군을 제한하고 싶지 않은 채용 담당자·현업 리더.

**상황**

- 직무명 검색으로는 후보가 부족하거나 비슷한 이력만 반복해서 나온다.
- 직무가 다른 후보의 경험을 채용 직무와 연결해 판단하기 어렵다.
- AI 추천 점수보다 실제 일치 역량과 문장 근거가 필요하다.
- 공고 작성 시 역할과 역량 조건을 일관되게 정리하기 어렵다.

**핵심 요구**

1. 공고의 필수·우대 역량에 맞는 후보를 빠르게 보고 싶다.
2. 직무명이 달라도 전이 가능한 역량을 가진 후보를 놓치고 싶지 않다.
3. 일치·부족 역량과 경력 조건을 분리해 판단하고 싶다.
4. AI가 만든 공고도 담당자가 통제 가능한 조건 안에서 검토하고 싶다.

**브랜드 메시지**

`직무명으로 보이지 않던 후보를, 역량 근거로 발견합니다.`

### 3.4 보조 타깃 — 회사와 공고를 탐색하는 구직자

가상 회사와 공고를 둘러보고 지원 흐름을 체험하는 사용자는 현재 보조 타깃이다. 회사 탐색 자체가 핵심 차별점은 아니며, 개인의 역량 분석 결과가 실제 기회로 이어지는 흐름을 보여주는 역할을 한다.

### 3.5 현재 핵심 타깃이 아닌 사용자

- 실제 경험 없이 성향만으로 진로를 정하려는 사용자
- 사람의 검토 없이 AI가 채용 여부를 자동 결정하기 원하는 기업
- 단순 채용공고 검색이나 공고 게시판만 필요한 사용자
- 실제 지원·연락·전형 자동화를 즉시 사용하려는 기업

이 기능들은 현재 제품 범위 밖이거나 커리어 내비의 핵심 가치와 맞지 않는다.

## 4. 핵심 가치

브랜드에서 반복할 핵심 가치는 세 가지다.

### 가치 1. 발견 — 이름 밖의 가능성을 찾는다

현재 직무명과 같은 결과만 보여주는 데 그치지 않는다. 여러 직무에서 함께 쓰이는 전이 가능한 역량을 찾아, 사용자가 미처 생각하지 못한 경로와 기업이 검색하지 못한 후보를 드러낸다.

**기능으로 증명하는 방법**

- 개인 결과의 `이 길도 있어요`
- 기업 결과의 `직무명이 다른 역량 전환 후보`
- 동일 직무 여부와 역량 적합도를 분리한 표시

### 가치 2. 설명 — 점수보다 근거를 먼저 보여준다

추천의 목표는 높은 숫자를 만드는 것이 아니라 사용자가 판단할 수 있는 근거를 제공하는 것이다. 보유 역량, 대체 가능한 역량, 부족 역량, 이력서 문장과 공고 표본을 함께 보여준다.

**기능으로 증명하는 방법**

- 필수·우대 역량별 충족 상태
- 이력서와 후보 데이터의 역량 문장 근거
- 부족 역량과 첫 학습 단계
- 공고 수와 역량 등장 비율에 기반한 가중치

### 가치 3. 연결 — 개인과 기업이 같은 역량 언어를 쓴다

개인 추천과 기업 추천은 별개의 AI 기능이 아니다. 같은 직무·역량 ID와 수요 가중치를 반대 방향으로 사용한다. 개인이 설명한 경험이 기업 공고의 요구 조건으로 이어질 수 있는 구조다.

**기능으로 증명하는 방법**

- 개인: `내 역량 → 갈 수 있는 직무`
- 기업: `공고의 요구 역량 → 맞는 사람`
- 회사·공고 데이터와 추천 결과의 공통 역량 계약

### 신뢰 원칙. AI는 해석하고, 점수는 코드가 계산한다

AI는 이력서의 문장을 해석하고 공고 문구 초안을 만든다. 직무·역량 ID, 적합도와 추천 순위는 정해진 코드가 계산한다. AI가 찾은 역량도 원문에서 다시 확인하며, 가상 데이터와 저장되지 않는 기능을 화면에 명시한다.

이 원칙은 별도의 네 번째 홍보 문구라기보다 `발견·설명·연결`을 믿을 수 있게 만드는 기반이다.

## 6. 핵심 사용자 흐름

### 6.1 개인

```text
샘플 선택 또는 이력서 입력
        ↓
현재 경험에서 역량 추출
        ↓
갈 수 있는 경로 3개와 숨은 경로 확인
        ↓
보유·부족 역량과 문장 근거 검토
        ↓
관련 회사·공고 또는 첫 학습 단계 확인
```

사용자가 얻어야 하는 최종 감정은 “AI가 나를 평가했다”가 아니라 **“내가 해온 일이 어디에 쓰일 수 있는지 이해했다”**다.

### 6.2 기업

```text
회사·기존 공고 선택 또는 새 공고 작성
        ↓
필수·우대 역량과 경력 조건 확인
        ↓
지원자·인재풀을 역량 기준으로 정렬
        ↓
직무명이 다른 전환 후보 발견
        ↓
일치·부족 역량과 문장 근거를 보고 사람에게 검토
```

기업이 얻어야 하는 최종 감정은 “AI가 사람을 골랐다”가 아니라 **“기존 검색에서 놓친 후보를 검토할 근거가 생겼다”**다.

## 7. 포지셔닝과 차별점

### 7.1 포지셔닝 문장

> 커리어 내비는 직무 전환을 고민하는 경력자와 전환 가능성을 함께 보는 채용 담당자를 위해, 이력서와 채용공고를 공통 역량 체계로 연결하고 추천 이유를 근거와 함께 보여주는 역량 기반 커리어·채용 서비스다.

### 7.2 비교 기준

| 비교 대상 | 주로 답하는 질문 | 커리어 내비가 추가로 답하는 질문 |
|---|---|---|
| 채용공고 검색 | 어떤 회사가 이 직무를 채용하는가? | 내가 가진 역량이 어떤 다른 직무와 연결되는가? |
| 진로·적성 검사 | 나에게 어떤 일이 어울리는가? | 실제로 해온 일 중 무엇이 그 직무의 요구와 겹치는가? |
| 이력서 AI 도구 | 이력서를 어떻게 잘 쓸 것인가? | 적힌 경험이 어떤 커리어 경로와 후보 가능성을 만드는가? |
| 지원자 검색·ATS | 같은 직무 경력자는 누구인가? | 직무명은 다르지만 요구 역량을 가진 사람은 누구인가? |

### 7.3 차별점을 말하는 순서

1. **양방향성** — 개인과 기업을 같은 역량 체계로 연결한다.
2. **숨은 연결** — 직무명이 다른 경로와 후보를 따로 드러낸다.
3. **설명 가능성** — 점수와 함께 역량·문장·공고 빈도 근거를 보여준다.
4. **AI 역할 제한** — 문장 해석과 초안은 AI, 점수와 조건은 코드가 담당한다.

## 8. 브랜드 기준

### 8.1 브랜드 핵심

| 항목 | 기준 문구 |
|---|---|
| 브랜드 본질 | **가능성의 방향을 근거로 보여주는 안내자** |
| 핵심 태그라인 | **직무명이 아니라 역량으로** |
| 공통 약속 | 지금까지 해온 일이 어디로 이어지는지 데이터와 근거로 보여드립니다. |
| 개인 메시지 | 해온 일 안에서, 다음 길의 근거를 찾습니다. |
| 기업 메시지 | 직무명으로 보이지 않던 후보를, 역량 근거로 발견합니다. |
| 행동 유도 | 내 다음 경로 보기 · 역량으로 후보 보기 |

핵심 태그라인은 개인·기업 화면, 공유 이미지와 발표 자료에서 바꾸지 않는다. 보조 문구만 대상과 화면에 맞춰 조정한다.

### 8.2 이름의 의미

`내비`는 목적지를 강제로 정하지 않고 선택 가능한 경로와 필요한 정보를 안내한다. 따라서 결과를 확정적으로 예언하거나 사용자를 등급화하는 표현보다 **경로·방향·연결·근거·다음 단계**의 언어를 사용한다.

### 8.3 메시지 구조

브랜드 설명은 다음 순서를 기본으로 한다.

```text
문제     같은 일을 해도 직함이 달라 서로를 놓칩니다.
해결     직무명이 아니라 역량으로 연결합니다.
개인     갈 수 있는 다음 경로와 준비할 역량을 보여줍니다.
기업     직무명 검색으로 보이지 않던 후보를 발견합니다.
신뢰     AI는 해석하고, 점수는 코드가 계산합니다.
```

### 8.4 말투와 성격

| 지향 | 설명 |
|---|---|
| 차분함 | 가능성을 과장하지 않고 확인된 근거를 먼저 말한다. |
| 구체성 | `잘 맞습니다`보다 `필수 역량 6개 영역 중 4개를 충족합니다`라고 말한다. |
| 존중 | 부족 역량을 결격 사유가 아니라 확인·준비할 항목으로 표현한다. |
| 안내 | 사용자를 평가하거나 명령하지 않고 다음 선택지를 보여준다. |
| 투명성 | 가상 데이터, 추정치, 외부 AI 전송과 저장 범위를 명시한다. |

### 8.5 사용할 표현과 피할 표현

| 사용 | 피함 | 이유 |
|---|---|---|
| 갈 수 있는 경로 | 천직·운명의 직업 | 가능성을 확정하지 않음 |
| 역량 적합도 | 합격 확률 | 현재 점수는 합격 예측 모델이 아님 |
| 확인이 필요한 역량 | 탈락 요인·결격 역량 | 부족을 사람의 결함처럼 표현하지 않음 |
| 추천 인재·미지원 | 잠재 지원자 | 실제 지원 의사나 연락 가능성을 가정하지 않음 |
| AI 초안·담당자 검토 | AI 자동 채용 | 사람이 최종 판단한다는 원칙 유지 |
| 공고 데이터 기준 | 객관적으로 완벽한 결과 | 표본과 데이터 한계를 인정 |

### 8.6 시각 언어

- **청록**: 보유 역량, 연결, 선택, 정상 완료
- **앰버**: 숨은 경로, 직무 전환 후보, 검토 경고
- **중립색**: 본문, 메타데이터, 비활성 정보
- 부족 역량에는 위험·탈락을 연상시키는 강한 빨강을 기본색으로 사용하지 않는다.
- 개인과 기업은 같은 브랜드 체계의 두 입구이므로 한쪽만 우위로 보이는 시각 위계를 만들지 않는다.

## 9. AI와 데이터 활용 원칙

### 9.1 AI 역할

| AI가 하는 일 | 코드가 하는 일 |
|---|---|
| 이력서 문장에서 직무·산업·역량 후보 추출 | 등록된 직무·역량 ID 검증 |
| 채용공고 제목·소개·주요 업무 문구 초안 | 필수·우대 역량, 경력 조건과 적합도 결정 |
| 사람이 읽기 쉬운 설명 문장 생성 | 점수·순위 계산과 금지 표현 검사 |

### 9.2 데이터 원칙

- 추천 근거와 목업용 가상 데이터를 구분한다.
- 회사 18개, 공고 48개, 후보 72명과 지원 이력 288건은 서비스 흐름 시연용이다.
- 가상 데이터는 추천 품질의 정답으로 사용하지 않는다.
- 실제 서비스 전환 시 현재 필드 계약을 유지하고 실제 공급원 데이터로 교체한다.
- 이력서와 분석 결과는 현재 서버·DB에 저장하지 않는다.

## 10. 현재 범위와 확장 범위

### 현재 목업에서 증명하려는 것

1. 개인과 기업이 같은 역량 체계를 반대 방향으로 사용할 수 있다.
2. 직무명이 다른 경로와 후보를 별도로 발견할 수 있다.
3. 추천 결과를 보유·부족 역량과 문장 근거로 설명할 수 있다.
4. AI의 역할을 문장 해석·초안에 제한하고 점수를 코드로 재현할 수 있다.
5. 실제 데이터가 들어올 필드 구조로 사용자 흐름을 미리 검증할 수 있다.

### 현재 증명하지 않은 것

- 추천 결과가 실제 이직·합격·정착 확률을 높인다는 것
- 적합도 점수가 합격 확률이라는 것
- 가상 후보가 실제 지원 의사나 연락 가능성이 있다는 것
- 실제 회사 운영에 필요한 인증·권한·저장·개인정보 처리가 완성됐다는 것

### 실제 서비스 전환 시 우선순위

1. 개인·기업 인증과 권한
2. 이력서 파일 파싱과 다건 처리
3. 실제 공고·지원자 저장 API
4. 개인정보 동의·보관·파기 정책
5. 행동 로그와 추천 결과 피드백
6. 실제 전환·입사·정착 결과를 이용한 품질 검증

## 11. 기획 가설과 검증 지표

현재 분석 로그가 없으므로 아래는 성과가 아니라 **검증해야 할 제안 지표**다.

| 가설 | 확인 행동 | 제안 지표 |
|---|---|---|
| 사용자는 직함 밖의 경로에서 새로운 가치를 느낀다. | `이 길도 있어요` 상세를 연다. | 숨은 경로 상세 열람률 |
| 설명 근거가 추천 신뢰를 높인다. | 역량 근거를 펼치고 다음 단계로 이동한다. | 근거 상세 열람률·추천 도움 여부 |
| 기업은 다른 직무의 후보도 검토할 의향이 있다. | 전환 후보 필터를 켜고 상세를 연다. | 전환 후보 상세 열람률 |
| 공고 조건 조정이 후보 탐색에 도움 된다. | 역량을 바꾸고 인재풀을 다시 계산한다. | 공고 수정 후 재평가 실행률 |
| 양방향 구조가 서비스 차별점으로 이해된다. | 설명 후 개인·기업 흐름을 정확히 말한다. | 5초 메시지 이해도 인터뷰 |

초기 검증에서는 숫자를 크게 모으기보다 타깃 사용자와 채용 담당자가 결과를 어떻게 해석하는지 관찰해야 한다. 특히 “점수를 합격 확률로 오해하는가”, “숨은 경로가 새롭지만 납득 가능한가”를 먼저 확인한다.

## 12. 브랜딩 활용 요약

### 12.1 랜딩·포스터용

**헤드라인**

직무명이 아니라 역량으로 연결합니다.

**설명**

개인에게는 지금 가진 역량으로 갈 수 있는 다음 경로를, 기업에는 직무명으로 보이지 않던 후보를 근거와 함께 보여드립니다.

**신뢰 문구**

AI는 경험을 해석하고, 적합도는 채용공고 기반 역량 규칙으로 계산합니다.

### 12.2 개인 화면용

**헤드라인**

내가 갈 수 있는 다음 커리어

**설명**

이력서에서 확인한 역량으로 경로 3개와 준비할 첫 단계를 보여드립니다.

### 12.3 기업 화면용

**헤드라인**

직무명으로는 보이지 않는 지원자

**설명**

채용공고의 요구 역량으로 후보를 다시 보고, 일치·부족 역량의 근거까지 확인합니다.

### 12.4 발표용 30초 설명

> 같은 일을 해도 회사마다 직무명이 달라 개인과 기업이 서로를 놓칩니다. 커리어 내비는 이력서와 채용공고를 298개 역량의 공통 언어로 바꿉니다. 개인에게는 갈 수 있는 다음 경로를, 기업에는 직무명 검색으로 놓친 후보를 보여줍니다. AI는 문장을 해석하지만 점수는 만들지 않습니다. 추천 결과는 채용공고의 요구 역량과 사용자 경험의 문장 근거로 설명합니다.
