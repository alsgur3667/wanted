# Career Navi · Codex UI 시안 v5

랜딩을 제외한 제품 화면 22개의 검토용 시안입니다. 기업 화면의 배경과 공통 배너를 정리하고, 로그인·분석 화면에 기존 SVG 애니메이션을 연결했습니다.

## 먼저 열어볼 파일

1. 저장소를 받은 뒤 이 폴더의 **[review.html](review.html)**을 브라우저에서 여세요. 별도 설치나 서버 없이 열립니다.
2. 왼쪽에서 화면을 선택하고 `개선 v5 / 이전 v4 / 나란히`, `PC / 모바일`로 비교합니다.
3. 로그인·분석 화면은 `개선 v5`에서 SVG가 실제로 움직입니다. 분석 완료 시안은 약 4.5초 후 완료로 전환됩니다.
4. 구현을 이어가실 때는 **[작업 인수인계](../../../docs/CODEX_UI_V5_HANDOFF.md)**를 먼저 읽어주세요.

GitHub 파일 페이지는 HTML을 웹사이트처럼 실행하지 않습니다. 브랜치를 내려받거나 `Code → Download ZIP`으로 받은 뒤 압축을 풀어 열어주세요. 이 브랜치의 기존 `/preview/*-v2` Next.js 화면과 이번 정적 v5 시안은 서로 다른 결과물입니다.

```sh
git fetch origin
git switch --track origin/feature/redesign-preview-v2-codex
```

## 파일 구성

| 파일 | 용도 |
|---|---|
| `review.html`, `review-v5.*`, `manifest.js` | 22개 화면의 v4·v5 비교 |
| `index.html` | 화면 이동과 예시 입력이 가능한 정적 시안 |
| `screens.*`, `refine.*`, `cohesion.*` | 화면 구성과 단계별 스타일. **v5 변경은 `cohesion.*`가 마지막으로 적용** |
| `animation.bundle.*` | 기존 React SVG 컴포넌트를 담은 실행 파일 |
| `animation-entry.tsx.txt`, `build-animation.cjs` | SVG 연결 코드와 번들 재생성 도구 |
| `shots/` | v5 PC·모바일 이미지 44개 |
| `previous/` | 비교용 v4 PC·모바일 이미지 44개 |
| `assets/` | 이미지와 내장 글꼴 |

이미지·글꼴·스크립트를 함께 사용하므로 HTML 한 파일만 옮기지 말고 **폴더 전체**를 전달해주세요. 운영체제의 동작 줄이기 설정이 켜져 있으면 기존 컴포넌트에 따라 애니메이션이 생략됩니다.

## SVG 번들을 다시 만들 때

보기만 할 때는 필요하지 않습니다. 기존 프로젝트 컴포넌트 변경을 시안에도 반영할 때, 저장소 루트에서 실행합니다.

```sh
npm ci
node output/design-mockup/codex-v5/build-animation.cjs
```

현재 잠금 파일에 포함된 `esbuild`를 사용합니다. `.tsx.txt`는 Next.js 타입 검사에 시안 전용 진입점이 섞이지 않도록 둔 소스 텍스트입니다. 실제 앱에서는 번들을 import하지 말고 원래의 React 컴포넌트를 재사용합니다.

## 범위

실제 로그인·AI 분석·지원·외부 전송은 실행하지 않으며, 기업·인물·점수는 예시입니다. 스크린샷은 자동 갱신되지 않습니다. 시안 코드를 바꾸면 PC·모바일 이미지를 다시 캡처해야 합니다.

서비스 안내와 하단 산 배너에는 첨부 이미지의 해당 영역을 사용했습니다. 특히 하단 배너의 문구와 버튼은 이미지에 포함되어 있어 최종 서비스에 그대로 쓰기에는 제약이 있습니다. 적용 전 준비할 내용은 인수인계 문서에 적었습니다.
